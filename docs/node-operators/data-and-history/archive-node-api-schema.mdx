<Subhead>
The GraphQL schema definition of the Archive Node API, schema version 2.0.

This page is the schema that the [Archive Node API](/node-operators/data-and-history/archive-node-api) 2.0.0 serves. The schema definition language (SDL) below is the full contract: every root query under `type Query`, every input type and every output type.

## Fetch the schema as a file

| Source | URL | Use it for |
|---|---|---|
| This site | `https://docs.minaprotocol.com/archive-node-api/schema.graphql` | Code generation, AI agents, and tools. Plain text, no authentication |
| The repository | `https://github.com/o1-labs/Archive-Node-API/blob/main/schema.graphql` | The source of truth, with its history |
| Your own instance | `http://localhost:8080` with `ENABLE_INTROSPECTION=true` | The schema that one deployment serves |

```sh
# The published 2.0 schema
curl -sO https://docs.minaprotocol.com/archive-node-api/schema.graphql

# The schema of your own instance, through introspection
npx get-graphql-schema http://localhost:8080 > schema.graphql
```

Introspection is off by default. The server answers an introspection query only when `ENABLE_INTROSPECTION=true`. Keep it off on a public instance and use the published file instead.

The schema follows semantic versioning, and a server reports the version it speaks through the `schemaVersion` query. The [Schema stability](/node-operators/data-and-history/archive-node-api#schema-stability) section explains what a minor and a major release change.
